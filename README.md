# ChatYou

A real-time MERN stack chat application with Socket.io.

## Tech Stack
- **Frontend:** React 17, styled-components, socket.io-client
- **Backend:** Node.js, Express, Socket.io
- **Database:** MongoDB Atlas

## Setup

### Server
```bash
cd server
npm install
npm start
```

### Client
```bash
cd public
npm install
npm start
```

> Set your `MONGO_URL` in `server/.env` before starting.
